# Khoj The Search

**Time Limit: 1 Sec**  
**Memory Limit: 264 MB**

So, the ducks of tUKCS have finally arrived on Earth. But they have faced a new issue right now. They are totally new on Earth so the commander of the tUCKS Special Force contacted a friend of his on Earth to be their guide. The guide gave them a location to come after “d” days and search for him in that location. The location contains a different number of guards in specific days. The force needs to know the day name to send solider according to the number of guards. So, the special force initiated an operation named “Khoj The Search”. Their programmer scientist will help them to make an algorithm to know the day name after “d” days and they know the current day name.

## Input

The input consists of two lines. The first line contains a string s — the name of the day.

It is guaranteed that input will contains one of these day names: "Monday", "Tuesday", "Wednesday", "Thursday", "Friday", "Saturday", and "Sunday".

The second line contains an integer d (0 ≤ d ≤ 10^9) — the number of days.

## Output

**Print the name of the day after d days.**

## Example

Sample Input 1

```
Wednesday
5
```

Sample Output 1

```
Monday
```

Sample Input 2

```
Friday
10000000
```

Sample Output 2

```
Tuesday
```
