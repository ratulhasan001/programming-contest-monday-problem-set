# A Problem from Multiverse

**Time Limit: 1 Sec**  
**Memory Limit: 264 MB**

In the concept of “Multiverse”, there exists a chicken universe. The headquarter of chicken has a very advanced Chicken AI and Chicken Robots to defend their universe. Recently they have created a very special algorithm which can detect if a number can be divided only by 1 and itself which works only for decimal numbers. But they have faced a big problem. The numbers are all in binary form. So, they have come to you for solution. You have to fix their algorithm so that they can detect that kind of specific number and make the algorithm successful.

## Input

First line contains T, number of test cases.

Next T lines contains total T binary numbers.

Constraint of binary number length <= 19

## Output

Print TRUE if you can detect that kind of number otherwise FALSE.

## Example

Sample Input 1

```
5
10
100
111
101000
1000111001
```

Sample Output 1

```
YES
NO
YES
NO
YES
```
